# Security

Please report vulnerabilities in the AISEOgic service or connector **privately** by email to **info@aiseogic.com** with the subject "Security report". Include what you found, how to reproduce it, and the time it happened. Please do not open a public issue for security problems and do not access other users' data.

This repository contains only documentation and example configuration. It holds no credentials; if you ever find a secret in it, tell us at the same address.
